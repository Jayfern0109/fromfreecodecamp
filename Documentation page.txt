      <p>GitHub is a web-based platform that hosts Git repositories and provides tools for collaboration.</p>
      <p>This guide introduces you to the basics of using Git and GitHub effectively.</p>
      <code>git --version</code>
      <code>git config --global user.name "Your Name"</code>

        <li>Branch management</li>

      <p>Download and install Git from the official site: git-scm.com.</p>
      <p>Create an account on GitHub.com and set up your profile.</p>
      <code>git init</code>
      <code>git clone https://github.com/your-username/your-repo.git</code>
      <ul>
        <li>Download Git</li>
        <li>Create GitHub account</li>
        <li>Configure Git locally</li>
      </ul>

    <section class="main-section" id="Common_Git_Commands">
      <header>Common Git Commands</header>
      <p>These commands help you perform everyday Git operations.</p>
      <p>Make sure you are in your project directory before running them.</p>
      <code>git add .</code>
      <code>git commit -m "Initial commit"</code>
      <code>git push origin main</code>
      <ul>
        <li>git status</li>
        <li>git log</li>
        <li>git diff</li>
      </ul>
    </section>

    <section class="main-section" id="Branching_and_Merging">
      <header>Branching and Merging</header>
      <p>Branches let you work on features separately from the main codebase.</p>
      <p>Merging integrates changes from one branch into another.</p>
      <code>git branch feature-xyz</code>
      <code>git checkout feature-xyz</code>
      <code>git merge main</code>
      <ul>
        <li>Create branch</li>
        <li>Switch branch</li>
        <li>Merge changes</li>
      </ul>
    </section>

    <section class="main-section" id="Collaborating_on_Projects">
      <header>Collaborating on Projects</header>
      <p>Use GitHub to collaborate with others by forking, cloning, and submitting pull requests.</p>
      <p>Communication and clear commit messages are key to good collaboration.</p>
      <code>git pull origin main</code>
      <code>git remote add upstream https://github.com/original/repo.git</code>
      <code>git fetch upstream</code>
      <ul>
        <li>Fork repository</li>
        <li>Clone locally</li>
        <li>Submit pull request</li>
      </ul>
